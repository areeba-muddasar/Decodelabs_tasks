# 🎯 Tech Stack Recommender

AI-powered career path recommendation system using Content-Based Filtering.

---

## ✨ Features

- 🎯 Personalized job recommendations
- 📊 Visual match score charts
- 📋 Complete job directory (50 roles)
- 🔍 Search & filter by category
- 📈 Skill gap analysis
- ⚖️ Compare two job roles
- 💾 CSV export
- 🎨 Beautiful web UI with Streamlit

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Language | Python 3.14 |
| Web Framework | Streamlit |
| Data | pandas |
| ML | scikit-learn |
| Charts | Plotly |
