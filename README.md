# 🤖 DecodeLabs AI Internship Projects

Welcome to my **Artificial Intelligence Internship Projects** repository, developed during my **AI Internship at DecodeLabs — Batch 2026**.

This repository contains four practical projects covering **rule-based AI, supervised machine learning, content-based recommendation systems, and computer vision with OCR and object detection**.

Each project demonstrates a different aspect of Artificial Intelligence and Machine Learning, from building a conversational chatbot to developing machine learning classifiers, recommendation systems, and image recognition solutions.

## 🤖 Project 1 — Rule-Based AI Chatbot

A Python-based conversational chatbot that responds to user queries using predefined rules and a dictionary-based knowledge base.

### Highlights

- Interactive command-line chatbot
- Greeting and help commands
- AI, Machine Learning, Deep Learning, Python, and Data Science topics
- Input sanitization
- Name detection and memory
- Conversation history
- Session statistics
- Time and date commands
- Multiple variations for similar intents
- Fallback responses
- Colored terminal interface

## 🌸 Project 2 — Iris Data Classification

A supervised machine learning project using the **Iris Dataset** to classify flowers into three species using the **K-Nearest Neighbors (KNN)** algorithm.

### Highlights

- 150 Iris samples
- Three target classes
- Four input features
- Data preprocessing
- 80/20 train-test split
- Feature scaling using `StandardScaler`
- KNN classifier with K = 5
- Confusion Matrix
- Precision, Recall, and F1 Score
- Data visualization

📂 **Project Folder:** `Project2_Data_Classification`

📖 **Documentation:** [Project 2 README.md](<Project2_Data_Classification/Project 2 README.md>)

## 🎯 Project 3 — AI Tech Stack Recommender

A **Content-Based Recommendation System** that analyzes a user's skills and recommends relevant technology career roles using **TF-IDF Vectorization** and **Cosine Similarity**.

The project is presented through an interactive **Streamlit web application**.

### Highlights

- Content-Based Filtering
- TF-IDF Vectorization
- Cosine Similarity
- Similarity-score ranking
- Top-N recommendations
- Skill Gap Analysis
- Job Directory
- Search & Filter
- Job comparison
- Analytics dashboard
- Plotly visualizations
- Cold Start handling
- CSV export
- Custom CSS styling
- 50+ technology-oriented job roles

📂 **Project Folder:** `Project3_AI-Recommendation-Project`

📖 **Documentation:** [Project 3 README.md](<Project3_AI-Recommendation-Project/Project 3 README.md>)

## 🖼️ Project 4 — Image & Text Recognition

A Python-based **computer vision project** that performs **Optical Character Recognition (OCR)** and **Object Detection** on images.

The project combines image preprocessing, **Tesseract OCR**, and the **YOLOv8n pretrained model** to extract text and identify objects from input images.

### Highlights

- Optical Character Recognition (OCR)
- Image preprocessing
- Grayscale conversion
- Gaussian blur
- Adaptive thresholding
- Tesseract OCR integration
- OCR confidence checking
- YOLOv8 object detection
- YOLOv8n pretrained model
- `yolov8n.pt` model weights
- Confidence-based filtering
- Bounding box visualization
- Extracted text output
- Annotated detection output

📂 **Project Folder:** `Project4_Image_Text_Recognition`

📖 **Documentation:** [Project 4 README.md](<Project4_Image_Text_Recognition/Project 4 README.md>)
